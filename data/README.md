Datasets used in lectures and labs.

Keep files here small — under about 10 MB each, and ideally CSV or Parquet. Git is
not a data store: large binary files bloat the repository permanently, because the
history keeps every version forever.

For anything bigger, or for data you are not licensed to redistribute, put it on
institutional storage and add a download script here instead.
