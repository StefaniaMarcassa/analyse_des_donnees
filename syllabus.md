## Submitting assignments

Assignments are distributed through GitHub Classroom. For each one:

1. Click the invitation link. This creates a private repository for you.
2. Clone it, do the work, commit and push.
3. Automated tests run on your submission and report a score. You can push as many
   times as you like before the deadline — the last push before the cutoff counts.

Pushing is submitting. There is nothing else to hand in.
