## Getting the materials

If you just want to read the slides, click into `slides/` and open the PDF.

If you want to run the code, clone the repository so you can pull updates:

```bash
git clone https://github.com/YOUR-ORG/course-materials.git
cd course-materials
```

Before each lecture, get the latest version:

```bash
git pull
```
